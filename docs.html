Lymar Language & Tooling Reference

Complete technical specification for the Lymar language, compiler semantics, standard library modules, and CLI flags.

1. Syntax & Formal Grammar Summary

Lymar features a unified EBNF-like grammar parsed cleanly without ambiguous operator conflicts:

Declaration ::= FrameDecl | TraitDecl | FnDecl | VarDecl | ImportDecl
FrameDecl ::= "frame" Identifier [ ":" TraitList ] "{" FrameMember* "}"
TraitDecl ::= "trait" Identifier [ ":" TraitList ] "{" MethodSignature* "}"
FnDecl ::= ["pub" | "prot"] "fn" Identifier "(" ParamList ")" [ ":" TypeAnnotation ] Block
Visibility ::= "pub" | "prot" | /* default private for vars/fns */

2. Type System & Zero-Cost Error Unions

Primitive types include int, float, bool, str, and nil. Dynamic collections are typed as lists [T] and dictionaries {K: V}.

Error handling uses T? unions representing either a valid value of type T or an error condition. Propagation is zero-overhead at machine level.

3. Frames, Traits & Module Export Rules

Module Visibility Semantics

  • Frames & Traits: Natively exported at module scope by default without needing a pub prefix.
  • Variables & Functions: Private by default unless explicitly declared with pub or prot.
  • Frame Members: Fields and methods within a frame use explicit pub (public) or prot (protected to frame and subframes) modifiers.

4. Standard Library Module Breakdown

std.collections

High-performance Vector, ArrayList, HashMap, BTree, PriorityQueue, and BitSet types.

std.net & crypto

HTTP/TLS client & server, WSS websockets, AES-GCM encryption, SHA-256 digests.

std.ui & game

Retained UI tree, Immediate Mode GUI, Sokol accelerated graphics, Truetype rendering.

std.algorithm

Timsort, quicksort, binary search, range adapters, and high-speed regular expressions.

5. Compiler Commands & Tooling

lymar run <file.lm> — Execute source file instantly via the Register VM
lymar build <file.lm> -o <binary> — Compile to native executable via Fyra AOT backend
lymar check <file.lm> — Perform semantic, type, and ownership analysis without code emission
lymar fmt <file.lm> — Auto-format source code following canonical style
