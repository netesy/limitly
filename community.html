Language RFC Process Lifecycle

Major language features or breaking syntax proposals undergo open community peer review:

Stage 0: Draft

Initial discussion on GitHub or Discord.

Stage 1: Proposal

Formal markdown RFC pull request submitted.

Stage 2: Implementation

Compiler prototype created and tested.

Stage 3: Standard

Stabilized and included in official release.

Contributing to Lymar

The Lymar compiler (src/), standard library (std/), and Fyra native code generator backend are written in C++20 and Lymar itself. We welcome pull requests for bug fixes, performance optimizations, LSP features, and documentation improvements!

$ git clone https://github.com/lymarlang/lymar.git
$ cd lymar && make -j4
$ python3 tests/run_tests.py

Community Code of Conduct
