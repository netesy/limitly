Welcome! This guide takes you from zero to building fast, safe systems and GUI applications with Lymar.

1. Getting Started

Create a file named hello.lm with your favorite text editor: 

fn main(): int {
    print("Hello, Lymar!");
    return 0;
}

main();

Run it directly with the Register VM or build a native executable:

$ lymar run hello.lm
$ lymar build hello.lm -o hello
$ ./hello

2. Variables, Constants & Collections

Lymar uses var for mutable variables and val / const for immutable constants. Dynamic string interpolation uses braces "{var}". 

var name: str = "Lymar";
val year: int = 2025;

print("Welcome to {name} in {year}!");

// Dynamic collections
var items: [str] = ["Core", "Collections", "Graphics"];
items.append("Concurrency");

print("Total items: {len(items)}");

3. Control Flow & Exhaustive Match

Iterate over collections using iter (item in collection) and match patterns cleanly: 

var status: int = 200;

match (status) {
    200 => print("OK"),
    404 => print("Not Found"),
    500 => print("Server Error"),
    _   => print("Unknown Status")
}

4. Functions & Zero-Cost Error Unions (Type?)

Fallible functions append ? to their return type. Propagate errors inline with ? else fallbacks: 

fn parse_port(input: str): int? {
    if (len(input) == 0) {
        return err();
    }
    return ok(8080);
}

fn run_server() {
    var port: int = parse_port("8080")? else {
        print("Invalid port configuration");
        return;
    };
    print("Server listening on port {port}");
}

5. Frames & Traits (Exported Natively)

In Lymar, declarations (variables, functions, frames, traits) are private by default at module scope unless explicitly marked with pub or prot visibility. 

trait Renderable {
    fn draw();
}

frame Button: Renderable {
    pub var label: str;
    pub var width: int;

    pub init(lbl: str, w: int) {
        self.label = lbl;
        self.width = w;
    }

    pub fn draw() {
        print("Drawing button '{self.label}' ({self.width}px)");
    }
}

var btn = Button("Submit", 120);
btn.draw();

6. Structured Concurrency & Channels

Structured blocks ensure parallel or concurrent tasks complete before the enclosing scope exits: 

var ch = channel();

concurrent(ch = ch) {
    task(i in 1..5) {
        ch.send("Task {i} complete");
    }
}

iter (result in ch) {
    print("Result: {result}");
}
