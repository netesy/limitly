culling.lm API Reference

Module Overview

std/d3/culling.lm Bounding volumes and frustum culling. Pure math over Geometry + Matrix so it can be unit-tested without a renderer or window. Convention: matrices are row-major `data[row*4+col]`, column-vector multiplication (clip = M * v), translation in m[3], m[7], m[11].

frustum_planes Function

pub fn frustum_planes(vp: Matrix): list

Extract the six view-frustum planes from a view-projection matrix. Returns 24 floats: 6 planes x (a, b, c, d) with the plane equation a*x + b*y + c*z + d >= 0 meaning "inside" for world-space points. Order: left, right, bottom, top, near, far.
