_ensure_gpu_buffers Function

fn _ensure_gpu_buffers(geo: geom.Geometry): nil

Builds (once) the interleaved pos+normal+uv vertex stream and index stream for a Geometry and uploads them as gg buffers. Local-space data is transformed by the MVP uniform at draw time, so one buffer serves every mesh/instance that shares the geometry. Vertex record: 8 floats (pos3, normal3, uv2); missing UVs default to (0,0).

_ensure_material_texture Function

fn _ensure_material_texture(material: mtrl.Material): nil

Loads material.base_color_texture once and uploads it as a gg image. material.texture_state: 0 = not tried, 1 = ready (texture_id valid), -1 = failed (renderer falls back to flat material color).
