index.lm API Reference

Module Overview

std/hash/index.lm Non-cryptographic hash functions for hash tables, checksums, and general use. For cryptographic hashing (SHA-256, SHA-512, MD5, SHA-1), see std/crypto/hash.lm.

Computes the 32-bit Fowler-Noll-Vo (FNV-1a) hash of a byte array.
