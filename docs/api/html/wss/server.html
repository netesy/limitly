server.lm API Reference

Module Overview

Provides WebSocket server utilities built on the raw WebSocket client module. Operations that can fail return `T?Error` and carry a diagnostic code; the ones that cannot (`join`, `leave`, `broadcast` on a room) just return a count.

__room_keys Function

fn __room_keys(connections: dict): list

Keys of a connection table. `iter` inside a frame method aborts the compiler, so the loop lives in this free function and the methods walk the resulting list with a while loop. Dictionaries are walked with the two-variable form, `iter (key, value in dict)`.
