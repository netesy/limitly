Module Overview

std/events Typed OS/window event pump and queue. This is the SINGLE translation point from raw gg.poll_events() records into typed Event values. Both std.app (Fluent ui_context dispatch) and std.game (InputManager/IMGUI) consume this queue — neither calls gg.poll_events() directly, so events are never stolen between frameworks. Ownership model: exactly one consumer drains the queue per frame. The Fluent path drains via std.app.dispatch_ui_events(); the game path drains via poll_event() in Game.begin_frame(). Mixing both in one frame splits the stream — pick one.

pump_events Function

pub fn pump_events(): nil

pump_events drains gg.poll_events() once per frame and enqueues typed Events. This is the ONLY caller of gg.poll_events() above the gg layer — it is also the frame-publish boundary on the GPU backend, so it must run exactly once per frame regardless of which consumer drains the queue.

pub fn poll_event(): Event
