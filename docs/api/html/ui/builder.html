builder.lm API Reference

Module Overview

std/ui/builder.lm Single-pass hybrid builder: walks Widget tree ONCE, emits DrawList + HitZones. Retained mode in syntax and developer ergonomics, but immediate mode in execution: - Walks the composable Widget tree in a single linear pass - Emits flat DrawCmds and HitZones directly into a DrawList - The DrawList is cached and replayed by replay.lm each frame at zero cost - Interactive events hit-test against the flat HitZone list in O(n) time
