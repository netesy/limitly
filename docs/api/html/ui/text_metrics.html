text_metrics.lm API Reference

Module Overview

std/ui/text_metrics.lm Font metric provider for the retained UI — pixel-parity with the renderer when a graphics context exists, real advances otherwise. Parity chain (first hit wins): 1. gg.measure_text / gg.get_line_height — the RENDERER's own metrics context: same embedded font, same gfx_font_size_for_scale size mapping the draw path uses. Pixel-exact. 2. std.image.font system font at the renderer-mapped pixel size — real advances, possibly a different typeface than the embedded font (advances can differ slightly). 3. Heuristic: FALLBACK_CHAR_W per codepoint — headless/no-font. font_scale maps to renderer scale EXACTLY like replay(): font_scale < 1.5 -> scale 1 (13px), >= 1.5 -> scale 2 (20px). Callers must pass the DISPLAY string (textshape.prepare_display). Results are cached per "text#scale_milli" — each uncached query is an FFI call, which would break the per-frame zero-alloc budget (M5).
