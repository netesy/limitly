components.lm API Reference

Module Overview

std/ui/components.lm Zero-Cost Component Embedding Architecture for Lymar Retained UI. Replaces monolithic 60-field God objects with fine-grained, composable component frames utilizing Lymar's `embed` mechanism. Flattened fields have zero pointer overhead; promoted methods provide fluent builder ergonomics without wrapper allocations. Interaction slots are typed optional functions -- `(fn(): nil)?` -- never raw `any`, and every invocation routes through a fallible `EventResult?` pipeline so call sites carry no nil-check ladders.
