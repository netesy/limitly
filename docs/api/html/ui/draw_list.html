draw_list.lm API Reference

Module Overview

std/ui/draw_list.lm Flat, ordered GPU draw command list with zero-allocation buffer reuse. Emitted by widgets during tree.update's paint pass; replayed by replay.lm without recursion. Hit-testing lives in std.ui.tree — this module carries draw commands only.

dl_clip_balance Function

pub fn dl_clip_balance(d: DrawList): int

M5 batching audit: clip push/pop must balance over the emitted command stream or the GPU clip stack leaks state into the next frame. Returns the net balance — 0 means every ClipPush was matched by a ClipPop.
