motion.lm API Reference

Module Overview

std/ui/motion.lm Minimal tween driver for widget animation. Widgets call animate_to(id, prop, target, dur) when a visual state changes and read value(id, prop, fallback) each paint — the returned float eases toward the target. app.run_frame_step ticks the registry; while any tween is live it requests repaints so animation actually advances under elision. prop is an opaque per-widget slot (0=primary, 1=secondary, ...). Everything is float math — no allocations on the hot path beyond the small tween list itself.
