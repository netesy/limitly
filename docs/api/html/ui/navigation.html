navigation.lm API Reference

Module Overview

std/ui/navigation.lm Complete client-side router for Lymar UI applications. Concepts: Route — pattern string + builder function that returns a Widget Router — owns the route table, history stack, and current match RouterParams — key-value pairs extracted from a matched URL pattern Middleware — optional pre-navigation guard (e.g. auth check)
