container.lm API Reference

Module Overview

std/ui/container.lm M2 layout containers: Flow (row/column), Container (padded box), ScrollView. All children are [Component] trait objects. measure asks each child for its intrinsic size under loose constraints; arrange distributes the parent's Rect; paint recurses in order; on_event hit-tests children in reverse paint order (topmost first). Events arrive as scalars (trait dispatch cannot take managed args); ScrollView reconstitutes a scroll offset by adjusting the y coordinate before forwarding — children see content-space coordinates.
