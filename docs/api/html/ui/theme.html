theme.lm API Reference

Module Overview

std/ui/theme.lm Theming layer for the Component UI, backed by the canonical std.theme.types.Theme (the same type the presets produce). import std.ui.theme as uitheme; val pal = uitheme.palette(); // init-time snapshot self.surface = pal.surface; Live re-theming: uitheme.set_dark(); // swap preset + bump version tree.apply_theme(root); // walk tree, refresh widgets Widgets snapshot palette() in init and may implement on_theme_changed() to re-snapshot; tree.apply_theme drives that. Per-instance fields remain overridable — the palette only supplies defaults.

palette Function

pub fn palette(): Palette

Snapshot the active theme into a UI palette. Called per-widget init and per on_theme_changed — allocation happens only at those times, never per-frame.

elevation_shadow Function

pub fn elevation_shadow(pal: Palette, elev: int): shadow.Shadow?

Re-snapshot palette defaults on a widget after a theme swap. Widgets call this from on_theme_changed(); fields the user overrode keep their values only if the widget chose to preserve them — the convention is that on_theme_changed re-applies theme-derived fields.
