Module Overview

Standard Library Core Option — a staged frame template (roadmaps.md item 1b). `Option(T: type)` is a template, not a frame: each type argument mints a real, nominal frame (`Option(int)`, `Option(str)`, ...) on first request. Use it in a type position and construct through that annotation: var found: Option(int) = Option(true, 42); var empty: Option(int) = Option(false, nil); The bare template name is not constructible on its own — `Option(true, 42)` without a type context is a compile error, by design: an untyped Option would collapse back onto `any`. Absence without combinators is still just `T?` / `T | nil`; reach for Option when you want map/filter/unwrap_or chaining over a typed value.

Option Frame

frame Option

Staged optional wrapper template representing an optional value.

💡 Idiomatic Usage & Best Practice

Use `T?` for plain presence/absence; reach for `Option(T)` when functional combinators (`map`, `filter`, `unwrap_or`) are desired.

✨ Example: Idiomatic Usage
var opt: Option(int) = Option(true, 42);
if (opt.is_some()) {
    print("Value is: {opt.unwrap()}");
}
