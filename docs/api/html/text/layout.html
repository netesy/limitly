Module Overview

std/text/layout.lm Text measurement and line wrapping for std.text. Honesty note: widths are CODEPOINT counts times a per-glyph advance — the same 8px/char heuristic std.ui uses until real font metrics (std.font text_width) are wired through. Wide glyphs (CJK) and proportional fonts will under/over-estimate; that is a documented v1 limit, not silent wrongness. Breaks prefer spaces, then hard-break.

wrap_text Function

pub fn wrap_text(text: str, max_chars: int): list

Greedy word wrap. max_chars is in CODEPOINTS (consistent with measure_width's units). Prefers breaking at the last space that fits; hard-breaks overlong words. Empty input yields one empty line.
