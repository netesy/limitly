Module Overview

std/url/url.lm RFC 3986 Uniform Resource Identifier (URI) / URL parser and resolver.

URL Frame

frame URL

Represents a parsed Uniform Resource Locator (URL) conforming to RFC 3986. Decomposes URLs into scheme, user credentials, host, port, path, query, and fragment. Supports IPv6 bracketed hosts, default port inference, query parsing, and relative path resolution.

💡 Idiomatic Usage & Best Practice

Use `url.resolve("...")` to resolve relative hyperlinks against a base document URL.

Parameters

ParameterDescription
url_strOptional candidate URL string to parse immediately upon instantiation.
✨ Example: Idiomatic Usage
import std.url as url;
var u = url.URL("https://user:pass@example.com:8080/api/v1?page=1#section");
print("Host: {u.host}, Port: {u.port}, Path: {u.path}");
