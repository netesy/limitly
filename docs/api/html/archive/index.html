Module Overview

Entry Frame

frame Entry

Represents a single file or directory node stored inside an archive.

💡 Idiomatic Usage & Best Practice

Query `is_directory` before attempting to read text or binary content.

ℹ️ Note

Instances store the entry payload, uncompressed byte size, and compression method.

Parameters

ParameterDescription
nameRelative path within the archive hierarchy (e.g. "docs/readme.txt").
sizeUncompressed byte size. Inferred automatically if content is provided.
is_dirTrue if this entry represents a directory node.
contentRaw text or binary data contained within the entry.
methodCompression method applied (0 for Stored, 8 for Deflated).
✨ Example: Idiomatic Usage
var entry = Entry("hello.txt", content="Hello, World!");
print("Size: {entry.size()} bytes");

Archive Frame

frame Archive

Multi-entry archive container supporting TAR (USTAR) and ZIP serialization.

💡 Idiomatic Usage & Best Practice

Methods like `add_file` and `add_directory` return `self` for fluent chaining.

Parameters

ParameterDescription
pathOptional default filesystem path associated with this archive.
✨ Example: Idiomatic Usage
var arch = Archive();
arch.add_file("config.json", "{}");
var zip_data = arch.to_zip_bytes();
