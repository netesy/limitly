index.lm API Reference

Module Overview

std/path/index.lm Path module - Cross-platform path manipulation. The separator that gets written is the platform one (std.os.path_separator); both "/" and "\" are always accepted when reading, so a POSIX path can be manipulated on Windows and vice versa.

Path Frame

frame Path

Represents a filesystem path, providing methods for component decomposition, joining, normalization, and filesystem inspection.

💡 Idiomatic Usage & Best Practice

All join operations normalize redundant separators automatically.
