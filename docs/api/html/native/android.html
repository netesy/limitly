android.lm API Reference

Module Overview

std.native.android - Pure-Lymar Android windowing backend (NDK). Implements the std.native.types contract through std.ffi: - JNI via JNI_GetCreatedJavaVMs / AttachCurrentThread (libart.so) - ANativeWindow from a Surface jobject (libandroid.so) - ANativeWindow_lock/unlock for the framebuffer - ALooper/AInputQueue for the event stream (libandroid.so) No C glue, no sokol. The Lymar process runs inside ART; a Java host Activity supplies the Surface via set_native_surface(env, surface). All FFI args are scalars/pointers - no struct-by-value needed. Control blocks + event rings are ffi.alloc'd raw memory (same design as std.native.win32/linux) so native callbacks never touch Lymar heap objects.
