gpu_d3d11.lm API Reference

Module Overview

std.native.gpu_d3d11 - Pure-Lymar D3D11 compute driver. Implements a real GPU device layer entirely through std.ffi: COM vtable calls into d3d11.dll / dxgi.dll / d3dcompiler_*.dll, hand-marshaled D3D11_BUFFER_DESC / D3D11_SUBRESOURCE_DATA / MAPPED_SUBRESOURCE structs, and HLSL->DXBC shader compilation via D3DCompile. No C glue. This module is designed to be precompiled with `lymar build -shared` into a native library (gpu_d3d11.dll + .meta). The VM and AOT hosts then call its exports through the Lymar ABI (CompiledResolver) - native speed, one implementation shared by both backends. Scope: compute only (buffers, SRV/UAV, compile shaders, dispatch, readback). Vertex/pixel/mesh stages are a later milestone. VTable indices (stable D3D11 ABI, IUnknown occupies slots 0-2): ID3D11Device: Release=2 CreateBuffer=3 CreateSRV=7 CreateUAV=8 CreateComputeShader=18 ID3D11DeviceContext (incl. ID3D11DeviceChild slots 3-6): Map=14 Unmap=15 Dispatch=41 CopyResource=47 CSSetShaderResources=67 CSSetUnorderedAccessViews=68 CSSetShader=69 ID3DBlob: GetBufferPointer=3 GetBufferSize=4

gpu_uav_create_typed Function

pub fn gpu_uav_create_typed(buf: int, format: int, num: int): int

gpu_uav_create_typed builds a D3D11_UNORDERED_ACCESS_VIEW_DESC for a typed buffer view (e.g. RWBuffer with DXGI_FORMAT_R32_UINT=42) and creates the UAV. The 32-byte desc is zeroed, then Format/ViewDimension/Buffer fields are stored at their documented offsets.

gpu_dispatch Function

pub fn gpu_dispatch(shader: int, uavs: list, srvs: list, x: int, y: int, z: int): int

gpu_dispatch binds the shader plus UAV/SRV arrays and issues Dispatch. uavs/srvs are Lymar [int] lists of COM view pointers; pass empty lists to leave a slot class unbound.
