gpu_vulkan.lm API Reference

Module Overview

std.native.gpu_vulkan - Pure-Lymar Vulkan compute driver. Implements a real GPU device layer entirely through std.ffi: the Vulkan loader (vulkan-1.dll / libvulkan.so / libMoltenVK.dylib) is resolved with vkGetInstanceProcAddr and every command is invoked through foreign_call. All Vulkan structs are hand-marshaled into ffi.alloc'd memory - no C glue. This is the submission backend for Fyra's SPIR-V output: gpu_shader_create_spv() accepts SPIR-V words produced by the vendor/fyra spirv target and vkCreateShaderModule compiles them through the platform driver. Scope: compute only - first compute-capable queue family, host-visible + host-coherent memory (no staging copies), STORAGE_BUFFER descriptors (binding index == buffer list index), synchronous dispatch with fence wait. Vertex/pixel/mesh stages and device-local memory are later work. Struct layouts are x86-64 Vulkan 1.1 ABI (handles/pointers 8 bytes, enums/u32 4 bytes) taken from vulkan_core.h. Record layouts (ffi.alloc'd, returned as int handles): buffer record (64B): @0 VkBuffer, @8 VkDeviceMemory, @16 mapped ptr, @24 size, @32 VkDeviceSize allocSize pipe record (96B): @0 VkPipeline, @8 VkPipelineLayout, @16 VkDescriptorSetLayout, @24 VkDescriptorPool, @32 VkDescriptorSet, @40 max_bindings Designed for `lymar build -shared` -> native library (gpu_vulkan.dll + .meta); the VM and AOT hosts call its exports through the Lymar ABI.

gpu_init Function

pub fn gpu_init(): int

gpu_init creates the Vulkan instance, picks the first physical device with a compute-capable queue family, creates the device (64/16 shader features enabled so Fyra SPIR-V modules using Int64/Float64 validate), queue, command pool, one primary command buffer, and a fence. Returns 1 on success. Idempotent.

pub fn gpu_buffer_create(bytes: int): int

gpu_buffer_create allocates a VkBuffer plus host-visible+coherent memory and maps it. Returns the buffer record pointer (see header layout) or 0.

gpu_buffer_read Function

pub fn gpu_buffer_read(buf: int, dst: int, bytes: int): int

gpu_buffer_read downloads `bytes` from mapped memory to raw address `dst`. gpu_dispatch is synchronous (fence wait), so reads after it are safe.

gpu_shader_create_spv Function

pub fn gpu_shader_create_spv(code_ptr: int, code_size: int): int

gpu_shader_create_spv creates a VkShaderModule from SPIR-V words. `code_ptr` is a raw address holding `code_size` bytes of little-endian SPIR-V (4-byte aligned, multiple of 4). This is the entry point for Fyra's spirv backend output.

gpu_pipeline_create Function

pub fn gpu_pipeline_create(shader_module: int, max_bindings: int): int

gpu_pipeline_create builds the full compute pipeline for a shader module: descriptor set layout with `max_bindings` STORAGE_BUFFER bindings (binding i <-> buffers[i] at dispatch), pipeline layout, descriptor pool, one descriptor set, and the VkComputePipeline. Returns the pipe record pointer (see header layout) or 0.

gpu_dispatch Function

pub fn gpu_dispatch(pipe: int, buffers: list, x: int, y: int, z: int): int

gpu_dispatch updates the descriptor set with `buffers` (buffer record pointers; index i binds descriptor binding i), records bind-pipeline + bind-set + dispatch into the shared command buffer, submits with the fence, and waits. Returns 1 on success.

gpu_release Function

pub fn gpu_release(obj: int): int

gpu_release frees only the ffi record memory. Object teardown is gpu_shutdown's job.

gpu_shutdown Function

pub fn gpu_shutdown(): int

gpu_shutdown destroys device-level objects, the instance, and unloads the loader. Buffer/pipe records should be gpu_release'd first.
