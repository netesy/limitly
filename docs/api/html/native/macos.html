macos.lm API Reference

Module Overview

std.native.macos - Pure-Lymar macOS windowing backend (Cocoa/ObjC). Implements the std.native.types contract through std.ffi: - libobjc.dylib: objc_getClass / sel_registerName / objc_msgSend / objc_msgSend_stret / class_addMethod (for a Lymar-defined NSWindowDelegate giving us windowShouldClose/windowDidResize) - AppKit.framework loaded dynamically (no link-time dependency) - NSRect-by-value arguments via ffi struct support ([ffi.TYPE_STRUCT, ffi.TYPE_F64 x4]) No C glue, no sokol. The event pump pulls NSEvents via -[NSApplication nextEventMatchingMask:untilDate:inMode:dequeue:]. Control blocks + event rings are ffi.alloc'd raw memory so native callbacks never touch Lymar heap objects (same discipline as std.native.win32/linux).
