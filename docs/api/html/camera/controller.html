controller.lm API Reference

Module Overview

std/camera/controller.lm Interactive camera controllers: orbit (turntable around a target) and fly (first-person look + move). Both wrap Camera3D and recompute its view matrix from yaw/pitch state, so they compose with any projection type.

OrbitController Frame

frame OrbitController

Turntable controller: orbits `camera` around `target` at `distance`. Angles are radians; pitch is clamped to avoid gimbal flip at the poles.

FlyController Frame

frame FlyController

First-person fly controller: yaw/pitch look with WASD-style translation. Forward is -Z at yaw=pitch=0, matching Camera3D's default view direction.
