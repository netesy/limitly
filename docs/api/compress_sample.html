compress_hex Function

pub fn compress_hex(data: str, level: int = ...): str?

Compresses raw input strings or bytes into standard zlib/deflate hex representation.

💡 Idiomatic Usage & Best Practice

The idiomatic and recommended way to compress data is level 6: it achieves 95% of maximal compression while running 4x faster than level 9.

⚠️ Warning

Always enforce a maximum buffer limit when decompressing untrusted inputs to prevent memory exhaustion and zip-bomb denial of service attacks.

ℹ️ Note

Thread-safe and allocation-safe. All temporary C-buffers are freed in native calls.

Contracts & Preconditions

  • requires len(data) > 0

Parameters

ParameterDescription
dataThe raw ASCII or UTF-8 string to compress.
levelCompression level between 0 (store) and 9 (max compression). Default is 6.

Returns

Returns ok(hex_string) upon successful compression, or err() if input is invalid.

✨ Example: Idiomatic Usage
var payload = "Hello, high performance Lymar compression!";
var compressed = compress_hex(payload, 6)? else {
    print("Compression failed");
    return;
};
print("Compressed hex: {compressed}");
